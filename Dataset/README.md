# Dataset Repository

This directory hosts the data files used to train and evaluate the machine learning architectures.

## Data Profile
* **Source:** Kaggle Curated Repository ( with link for verification purpose:https://www.kaggle.com/datasets/taruntiwarihp/phishing-site-urls/data)
* **Target Feature Dimensions:** 549,346 records mapped across two columns: `URL` (string vector) and `Label` (binary category target classification: `Good` or `Bad`).
* **Included Entry:** `phishing_site_urls.xls` (Data sample utilized for training validation checkpoints).
